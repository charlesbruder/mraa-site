Site Manager

Update the Mizzou Rugby Alumni Association website — no technical skills needed. Enter the board password to get started.

Request a change

Describe what you'd like changed or added in plain English — like you're telling a helpful volunteer. Example: "Add a news post: the fall alumni weekend is October 10–12 in Columbia. Include the attached photo."

After you send a request, the site assistant works on it for a few minutes. When the status says Ready to preview, click View preview to see the change before anything goes live.
